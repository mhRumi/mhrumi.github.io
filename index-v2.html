Distilling Small Language Models for Real-World Tasks

How can we make large language models more efficient? Can smaller models achieve comparable performance on specialized tasks? What role does synthetic data play in model distillation? How does LLM-generated code affect software quality?

Large language models have revolutionized software engineering, but their computational requirements limit accessibility. In Distilling Small Language Models for Real-World Tasks Using Real and Synthetic Data, Mehedi demonstrates the feasibility of using small, distilled LLMs for critical software engineering tasks such as program repair and bug detection.

By combining real datasets with synthetic, teacher-generated data, this research bridges the gap between accuracy and efficiency, making AI-powered software engineering tools more accessible to practitioners and researchers with limited computational resources.

His complementary research on technical debt examines how LLMs are creating new challenges in software maintenance by analyzing the quality of LLM-generated code compared to handwritten code, highlighting important implications for long-term software sustainability.
